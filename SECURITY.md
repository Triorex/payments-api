# Security policy

Report vulnerabilities privately through **GitHub private vulnerability reporting**
(Security tab → "Report a vulnerability"). Do not open a public issue.

This service is on the Triorex paved road: every change passes the central security gates in
[Triorex/paved-road-platform](https://github.com/Triorex/paved-road-platform), and only images
signed by that platform can run in production.
